# Board

Kotoba's work is tracked on the **Kotoba** board in Kumiko (slug `kotoba`).
Name a card by id and title together: `c12 ("What it says")`.

## Labels

Independent axes: a card carries one from each that applies.

| Label                             | Meaning                                                                                                                          |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Feature, Bug, Design, Infra, Docs | The kind of work                                                                                                                 |
| **Owner decision**                | Waiting on the owner's call. Agents write the options and a recommendation on the card, never pick one, and do not build past it |
| **Action needed**                 | Waiting on something only the owner can do (an account, a console, a secret, a payment). The card holds the exact steps          |

A label added to the board gets a row here in the same pass.
